Mapas e serviços externos

Para mostrar os mapas, o seu browser pede imagens e dados diretamente a estes serviços, que ficam a saber o endereço de internet (IP) do seu aparelho, como em qualquer site:

  • Direção-Geral do Território (fotografias aéreas);
  • OpenStreetMap (mapa de estradas);
  • eBUPi (terrenos já identificados, só se ligar essa opção).

O desenho do seu terreno não é enviado a nenhum destes serviços.

O site está alojado no GitHub Pages, que regista dados técnicos das visitas (como o IP) por razões de segurança.

Os seus direitos
